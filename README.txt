ISTRI WALA RADIO - PERMANENT PLAYLIST VERSION

The 15 MP3 songs are bundled with this project.
There is NO Import Songs button.

Keep this structure:
Istri-Wala-Radio-Permanent/
  index.html
  playlist/
    01-Lag-Ja-Gale.mp3
    ...
    15-O-Mere-Dil-Ke-Chain.mp3

Recommended:
Open the whole folder in VS Code and run index.html with Live Server.

The songs are permanently included in this project folder. The browser does
not need to import them again after opening the project.
